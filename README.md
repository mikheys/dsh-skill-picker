# dsh-skill-picker

**Skill manager for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): a right-panel tab with checkboxes that decide which skills a chat may use — per chat or globally — with Russian titles, descriptions and categories.**

Менеджер навыков для DeepSeek Harness: вкладка «Навыки» в правой панели с галочками, русскими названиями и пояснениями. Включайте только то, что нужно для текущей задачи, — лишние навыки не попадают в каталог модели.

> The package is a local DSH bundle (installed from a folder), not an npm CLI tool. It adds one Host plugin, one right-panel tab, and two local HTTP endpoints.

---

## Что умеет

- **Вкладка «Навыки»** в правой панели и кнопка «Навыки» под полем ввода.
- **Две области**:
  - **«Этот чат»** — только текущая сессия (можно спрятать лишнее или вернуть глобально скрытый навык обратно);
  - **«Все чаты»** — глобальный набор: действует на все сессии, включая будущие и субагентов.
- **Русские названия, описания и категории** для навыков (переводятся в `russian.json`; для неизвестных навыков показывается оригинальное описание).
- Поиск, категории («Мои режимы», «Веб и дизайн», «Картинки и видео», «Документы и Office», «Blender и 3D», «DSH и плагины», «Разное»), кнопки «Все / Никакие / вкл / выкл» по категории.
- **Кнопка «Применить»**: изменения сохраняются одним пакетом — DSH переопубликует каталог навыков один раз, а не на каждый клик.
- **Скрытые навыки остаются доступны вручную**: модель их не видит (экономия контекста), но если написать `/имя-навыка` в сообщении, плагин подгрузит **настоящий текст** навыка.
- Выбор хранится в `~/.dsh/skill-picker/selections.json`; при перезапуске DSH и новых чатах применяется автоматически.

## Как это работает

- **Host-половина** (`index.js`) держит состояние `{ defaults, sessions }` и для каждого агента регистрирует в его собственной области (`agent.ctx`) одноимённые «теневые» навыки с `modelInvocable: false` и настоящим текстом навыка. Каталог модели читается в области агента, поэтому тень побеждает и навык исчезает из каталога **только этого чата**; остальные сессии не затронуты.
- **Client-половина** (`client.js`) регистрирует тип вкладки правой панели (`sidebarRightTabs.register`) и её тело в слоте `sidebar.right.pane.tab`, рисует список и ходит в локальные маршруты плагина.
- **Маршруты**: `GET /skill-picker/api/catalog?sessionId=…`, `POST /skill-picker/api/selection`, `GET /skill-picker/api/debug`. Защита: только localhost, проверка `Origin`/`Host`, для записи обязателен `application/json`.

Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Требования

- DeepSeek Harness Desktop/Web, проверено на `0.2.2-rc.1` (профиль `desktop`, Windows).
- Панель работает в Web-интерфейсе DSH (страница по HTTP-адресу). В нативном окне, если оно открывает UI не через HTTP, вкладка покажет ошибку связи — это ограничение транспорта.
- Навыки в каталоге DSH: стандартные roots (`~/.agents/skills`, `~/.dsh/skills`, `.agents/skills`, `.dsh/skills` проекта и кастомные каталоги режимов).

## Установка

1. Склонируйте репозиторий в стабильную папку, например:
   ```powershell
   git clone https://github.com/mikheys/dsh-skill-picker.git "$env:USERPROFILE\Documents\dsh-skill-picker"
   ```
2. Установите бандл в профиль DSH. Проще всего — попросить агента в DSH:
   > Установи локальный бандл из папки `C:\Users\<вы>\Documents\dsh-skill-picker` через плагин-менеджер (`install_bundle`).

   Агент вызовет `plugin_manager` с `action: install_bundle` и абсолютным путём к папке. После установки плагин появится в списке плагинов профиля.
3. Обновите страницу DSH (**Ctrl+R**) и нажмите кнопку **«Навыки»** под полем ввода (или: правая панель → «Старт» → карточка «Навыки»).

Удаление: удалить бандл `@local/dsh-skill-picker` в списке плагинов DSH (или `plugin_manager` → `remove_bundle`).

## Использование

1. Откройте панель «Навыки».
2. Вкладка **«Все чаты»**: снимите галочки с того, что не нужно в обычной работе, нажмите **«Применить»** — это уберёт лишние строки каталога из всех чатов.
3. Вкладка **«Этот чат»**: точечно верните нужное для конкретной задачи (пометка «включён для чата») или спрячьте лишнее (пометка «скрыт глобально»).
4. Для разового случая скрытый навык можно не включать: напишите в сообщении `/имя-навыка`.

## Настройка

- **Переводы** — `russian.json`: объект `{ "<name-навыка>": { "category", "title", "description" } }`. Незнакомые навыки показываются с оригинальным описанием.
- **Состояние** — `~/.dsh/skill-picker/selections.json`:
  ```json
  { "version": 2, "defaults": ["office"], "sessions": { "<sessionId>": { "hidden": [], "enabled": ["office"] } } }
  ```
  `defaults` — скрыто во всех чатах; `sessions` — исключения одного чата (`enabled` возвращает глобально скрытый навык).

## Нюансы

- Каталог навыков DSH и так попадает в контекст модели (имя + краткое описание на каждый навык); плагин только **уменьшает** этот список. Полный текст навыка загружается, как и раньше, по вызову `skill` — или по `/имя`.
- DSH переопубликовывает каталог при смене состава — каждое «Применить» добавляет одно сообщение-каталог в историю. Поэтому изменения и собраны под кнопкой, а не применяются на каждый клик.
- Глобальные галочки действуют и на субагентов.
- Плагин не меняет файлы навыков и не вмешивается в работу штатных навыков.
